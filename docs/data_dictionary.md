# Data dictionary

_Generated by `uv run python -m data_gen.describe` from dataset v0.1 (seed 20261020, 400 patients x 14 days). Distributions are computed from the data on disk._

Roles: **M** modifier (changes simulated physiology or drug response), **C** constraint (limits what-if options), **X** context (explains, no effect on the maths). Literature-based values behind each distribution are listed in `docs/parameters_to_verify.md`.
